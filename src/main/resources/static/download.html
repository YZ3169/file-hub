日常使用推荐

安装版

跟随安装向导完成设置，从开始菜单打开。

  • 按当前用户安装，无需管理员权限
  • 自动创建 FileHub 程序文件夹
  • 卸载保留已有文件与账号数据
前往 GitHub 下载 MSI
在发行版 Assets 中选择 .msi 文件
查看 SHA-256 校验值
解压即可启动

免安装版

解压完整文件夹，双击 FileHub.exe 打开。

  • 无需运行安装向导
  • 包含运行所需的 Java 环境
  • 数据仍保存在当前用户的数据目录
前往 GitHub 下载 ZIP
在发行版 Assets 中选择 -portable.zip 文件
查看 SHA-256 校验值
下载入口指向项目 GitHub Releases。更新说明与历史版本

安装更简单

内置 Java 运行环境与数据库，无需另外安装 Java、MySQL 或 Docker。安装版选择 D:\ 时，会自动安装到 D:\FileHub。

文件留在本机

文件、账号与设置保存在 %LOCALAPPDATA%\FileHubData。免安装版也使用此目录；迁移电脑前请退出程序并备份它。

打开后即可开始

首次注册的账号成为管理员。登录后选择文件上传；关闭窗口时，可选择最小化到托盘或退出程序。

下载前，你可能想知道

需要什么系统环境？

桌面版面向 Windows 10 / 11 x64，外壳需要 .NET Framework 4.8。独立窗口需要 Microsoft Edge WebView2 Runtime；如果启动时提示缺失，可从 Microsoft 官方页面安装。安装包内置 Java 环境，但不包含 WebView2 Runtime。

下载失败，或无法读取最新版本？

页面直接从 GitHub 获取版本与安装包。网络不通、GitHub 限流或发行版暂未提供安装包时，可以使用上方 GitHub 入口查看 Assets，或稍后重新获取。Source code 压缩包是项目源码，不是可直接运行的桌面版。

Windows 提示“未知发布者”怎么办？

当前桌面安装包未做代码签名，Windows 可能显示发布者提示。请确认文件来自本项目 GitHub Releases，并核对页面提供的 SHA-256 校验值；无法确认来源时不要运行。校验值可用 PowerShell 的 Get-FileHash -Algorithm SHA256 -LiteralPath '安装包路径' 查看。

本机的分享链接可以发给其他人吗？

桌面版只监听本机地址 127.0.0.1:18080，默认的分享链接只能在这台电脑上打开。需要跨电脑访问时，请按仓库文档部署服务器版。
